# Dubai Desert Adventures - Luxury Tourism Platform

A premium, ultra-modern full-stack web application for a luxury desert safari and tour company in Dubai. Built with a focus on high-end aesthetics, cinematic animations, and a seamless booking experience.

## 🚀 Features

- **Cinematic UI/UX**: Designed with 2026 aesthetics using Tailwind CSS, Framer Motion, and GSAP.
- **Premium Animations**: Smooth scrolling with Lenis and interactive 3D-style hover effects.
- **Full-Stack Architecture**: Next.js frontend with a dedicated Node.js/Express backend.
- **Robust Authentication**: JWT-based secure auth system with User and Admin roles.
- **Booking Engine**: Multi-step booking flow with real-time pricing and availability.
- **Admin Dashboard**: Comprehensive panel for managing tours, bookings, users, and analytics.
- **User Dashboard**: Personalized experience for managing bookings, wishlists, and loyalty points.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.

## 🛠️ Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS 4.
- **Animations**: Framer Motion, GSAP, Lenis.
- **Backend**: Node.js, Express, TypeScript.
- **Database**: MongoDB (Mongoose).
- **Icons**: Lucide React.

## 📁 Project Structure

```text
/client   - Next.js Frontend
/server   - Express.js Backend
```

## ⚙️ Setup Instructions

### Prerequisites
- Node.js installed
- MongoDB instance (local or Atlas)

### Backend Setup
1. Navigate to `/server`
2. Run `npm install`
3. Configure `.env` with your MongoDB URI and JWT Secret.
4. Run `npm run dev` to start the development server.

### Frontend Setup
1. Navigate to `/client`
2. Run `npm install`
3. Run `npm run dev` to start the Next.js app.
4. Open `http://localhost:3000` in your browser.

## 🎨 Design Philosophy
- **Colors**: Deep Black (`#0A0A0A`), Metallic Gold (`#D4AF37`), Desert Sand (`#C5A059`).
- **Typography**: Outfit (Sans) for modern clarity, Playfair Display (Serif) for luxury storytelling.
- **Glassmorphism**: Subtle blurs and borders to create depth and a premium feel.
